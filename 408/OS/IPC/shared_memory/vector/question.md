# question
在共享内存中创建并使用vector会发生什么


| 问题点                | 具体表现                                                                 |
|-----------------------|--------------------------------------------------------------------------|
| 内存分配不共享        | `vector`的底层数组由`new`分配在进程私有堆，其他进程无法访问（仅`vector`的元数据在共享内存）； |
| 析构函数跨进程调用    | 进程退出时，`vector`的析构函数尝试释放其他进程的内存，导致崩溃/内存泄漏；|
| 指针/迭代器失效       | 不同进程的虚拟地址空间独立，`vector`的指针/迭代器在其他进程中是无效地址；|
| 扩容时内存重新分配    | `vector`扩容（realloc）会分配新的私有堆内存，原共享内存中的数据链接断裂；|
